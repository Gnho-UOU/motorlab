# 수식 유도 노트

`engine/`의 수식이 어디서 나왔는지 정리한다. 면담에서 "왜 이 식인가"에 답할 수 있어야 하므로, 각 절은 **가정 → 유도 → 코드 위치** 순서로 쓴다. 기호는 `docs/ENGINE_SPEC.md` 1장과 같다(크기 불변 dq 변환, 전류·전압은 상 첨두값, p는 극쌍 수).

## 1. 정상상태 dq 전압 방정식 (기획서 5.1)

정상상태에서는 dq 자속이 시간에 따라 변하지 않으므로 자속 변화율 항이 사라지고, 회전 좌표계의 속도 기전력만 남는다.

```
vd = Rs·id − ωe·ψq
vq = Rs·iq + ωe·ψd          (ωe = p·ωm)
```

상수 파라미터 모델은 ψd = Ld·id + ψm, ψq = Lq·iq. 영구자석 자속 ψm은 d축에 있다.

코드: `ConstantParamModel.flux`, `.voltage` (`engine/model.py`)

## 2. 토크와 전력 수지 (기획서 5.2)

크기 불변 변환에서 3상 전력은 P = 1.5·(vd·id + vq·iq)이다. 전압식을 대입하면

```
vd·id + vq·iq = Rs·(id² + iq²) + ωe·(ψd·iq − ψq·id)
```

첫 항은 동손, 둘째 항이 기계 출력 Te·ωm이다. ωe = p·ωm이므로

```
Te = 1.5·p·(ψd·iq − ψq·id)
```

그래서 **P = Te·ωm + 1.5·Rs·I²** (I² = id² + iq²)가 항등식으로 성립한다. 이것이 테스트 T5다.

상수 파라미터를 대입하면

```
ψd·iq − ψq·id = (Ld·id + ψm)·iq − Lq·iq·id = ψm·iq + (Ld − Lq)·id·iq
Te = 1.5·p·[ψm·iq + (Ld − Lq)·id·iq]
```

첫 항은 자석 토크, 둘째 항은 릴럭턴스 토크다. IPMSM은 Ld < Lq이므로 id < 0일 때 둘째 항이 양수가 된다. (테스트 T7)

코드: `ConstantParamModel.torque`

## 3. 전류각 표현

`id = −Is·sinβ`, `iq = Is·cosβ`, β ∈ [0, 90°]. Is는 전류 벡터의 크기(첨두)다. 이때

```
Te(Is, β) = 1.5·p·[ψm·Is·cosβ + (Lq − Ld)·Is²·sinβ·cosβ]
```

(id·iq = −Is²·sinβ·cosβ에 (Ld − Lq)를 곱하면 (Lq − Ld)·Is²·sinβ·cosβ가 된다.)

## 4. MTPA 해석식 (기획서 5.3)

전류 크기 Is를 고정하고 토크를 최대로 하는 β를 찾는다. 표기를 줄이려고 ΔL = Lq − Ld로 둔다.

```
dTe/dβ = 0
⇒ −ψm·Is·sinβ + ΔL·Is²·(cos²β − sin²β) = 0
⇒ ψm·sinβ = ΔL·Is·(1 − 2·sin²β)
```

x = sinβ라 하면 2·ΔL·Is·x² + ψm·x − ΔL·Is = 0. 양의 근은

```
x = [−ψm + √(ψm² + 8·ΔL²·Is²)] / (4·ΔL·Is)
```

id = −Is·x이므로

```
id_MTPA = [ψm − √(ψm² + 8·ΔL²·Is²)] / (4·ΔL)
iq_MTPA = √(Is² − id²)
```

확인: 테스트 파라미터(ψm = 0.075, ΔL = 0.3 mH, Is = 250 A)에서 √(0.005625 + 0.045) = 0.225, id = (0.075 − 0.225)/(4·0.3e-3) = −125 A. ENGINE_SPEC의 손계산값과 같다.

비돌극(ΔL = 0)이면 토크가 ψm·Is·cosβ뿐이라 β = 0, 즉 id = 0이다. (테스트 T1. 위 식은 ΔL → 0에서 0/0 꼴이라 직접 대입하지 않고 극한으로 본다.)

코드: `mtpa_point` (`engine/operating.py`). 코드는 해석식을 쓰지 않고 β를 수치로 탐색한다. 해석식이 없는 맵 모델(P3)에서도 같은 함수가 동작해야 하기 때문이고, 해석식은 테스트 T2에서 정답지로만 쓴다.

## 5. 전압 제한과 기저속도 (기획서 5.3)

선형 변조 한계 Vmax = k_mod·Vdc (k_mod = 1/√3). 정상상태 전압 크기를 전개하면

```
vd² + vq² = (Rs·id − ωe·ψq)² + (Rs·iq + ωe·ψd)²
          = Rs²·I² + 2·ωe·Rs·(ψd·iq − ψq·id) + ωe²·|ψ|²
```

(교차항: 2·Rs·ωe·(iq·ψd − id·ψq) = 2·Rs·ωe·Te/(1.5p).) 이것을 vd² + vq² = Vmax²로 놓으면 ωe에 대한 이차식이다.

```
|ψ|²·ωe² + 2·Rs·(ψd·iq − ψq·id)·ωe + (Rs²·I² − Vmax²) = 0
ωe = [−b + √(b² − 4·a·c)] / (2·a),   a = |ψ|², b = 2·Rs·(ψd·iq − ψq·id), c = Rs²·I² − Vmax²
```

Imax의 MTPA점을 대입해 얻은 ωe를 p로 나눈 값이 **기저속도** ωm,base다. 이 속도까지는 전류 제한만 걸리고(MTPA 모드) 전압은 여유가 있다. Rs = 0이면 ωe = Vmax/|ψ|로 줄어든다(테스트 T3).

테스트 파라미터 값: |ψ| = √(0.05625² + 0.09743²) = 0.11251 Wb, ωe = 202.07/0.11251 = 1796 rad/s, ωm = 449.05 rad/s (4288 rpm).

코드: `base_speed` (`engine/operating.py`)

## 6. 약계자와 최고속도 (Rs = 0)

기저속도 위에서는 전압이 한계라서 |ψ|를 Vmax/ωe 이하로 줄여야 한다. d축 자속 ψd = Ld·id + ψm을 줄이려면 id를 더 음으로 한다(약계자). 전류 원 안에서 |ψ|가 가장 작은 점은 (id, iq) = (−Imax, 0)이다. 이때

```
|ψ|min = ψm − Ld·Imax        (ψm > Ld·Imax일 때)
ωe,max = Vmax / (ψm − Ld·Imax)
```

이 속도를 넘으면 영토크(영전류 포함)로도 전압을 맞출 수 없다(테스트 T4). 반대로 **ψm < Ld·Imax**(특성전류 ψm/Ld가 Imax 안쪽)이면 자속을 0까지 줄일 수 있어 속도 상한이 사라진다. 이때 고속에서는 전류 한계가 아니라 전압 한계만 걸리는 MTPV 영역이 나타난다.

## 7. MTPV (최대 토크/전압, Rs = 0)

속도가 충분히 높으면 전압 타원 위에서 토크가 최대인 점이 전류 원 안쪽에 있게 된다. 자속 크기를 Ψ = Vmax/ωe로 고정하고 자속각 δ로 매개화한다.

```
ψd = Ψ·cosδ,   ψq = Ψ·sinδ
id = (ψd − ψm)/Ld,   iq = ψq/Lq
Te = 1.5·p·(ψd·iq − ψq·id) = 1.5·p·ψq·[ ψd·(1/Lq − 1/Ld) + ψm/Ld ]
```

δ 한 변수에 대한 최댓값이 MTPV 점이다. 테스트 T8은 이 1차원 탐색을 정답지로 쓰고, 엔진의 2차원 탐색 결과와 비교한다. 엔진은 "전압 제한만 활성이고 전류가 Imax 미만"이면 이 영역으로 판정한다.

## 8. 운전 모드 판정 (기획서 5.3)

최대 토크 점에서 어느 제약이 활성인지로 나눈다.

| 전류 제한(I = Imax) | 전압 제한(\|v\| = Vmax) | 모드 |
| --- | --- | --- |
| 활성 | 비활성 | MTPA |
| 활성 | 활성 | FW (약계자) |
| 비활성 | 활성 | MTPV |

영전류에서도 전압이 Vmax를 넘는 속도는 `INFEASIBLE`로 표시한다.

## 9. 손실과 효율 (기획서 5.4)

**동손.** 3상이므로 P_cu = 3·(Is/√2)²·Rs = 1.5·Rs·(id² + iq²) (첨두값 기준 크기 불변 변환). 온도 보정은 Rs(T) = R20·(1 + α_cu·(T − 20)). α_cu는 출처와 함께 호출자가 준다.

**철손.** 치와 요크를 따로 보고 Bertotti 분리식(히스테리시스 + 와전류)을 쓴다.

```
P_fe = Σ_k m_k · (k_h·f·B_k^β + k_e·f²·B_k²),   f = p·ωm / 2π
B_k = c_k·|ψ|,   |ψ| = √(ψd² + ψq²)
```

자속이 같을 때 히스테리시스는 f에 비례, 와전류는 f²에 비례한다(테스트에서 속도 2배 → ×2, ×4 확인). B_k를 |ψ|에 비례시키는 것은 근사이고, 환산계수 c_k는 권선 턴수와 치·요크 단면적에서 정해진다. P3에서 FEA 자속밀도와 비교한다. 이상(excess) 손실은 생략했다.

**기계손.** P_mech = a·ω + b·ω³ (베어링 마찰은 속도에 비례, 풍손은 세제곱).

**효율.** 철손은 토크에 반영하지 않고 입력에만 더한다.

```
P_shaft = Te·ωm
P_in  = P_shaft + P_cu + P_fe
P_out = P_shaft − P_mech
η = P_out / P_in
```

철손·기계손을 0으로 두면 2절의 전력 수지에 의해 P_in = 1.5·(vd·id + vq·iq)가 되어, 전압식으로 계산한 전기 입력 전력과 일치한다(테스트로 확인). 그리고 P_in − P_out = P_cu + P_fe + P_mech가 항상 성립한다.

코드: `copper_loss`, `iron_loss`, `mech_loss`, `loss_breakdown` (`engine/losses.py`)

## 10. 효율맵의 동작점 선택 (`optimal_current_map`)

(토크 T, 속도 ω)마다 전류 크기가 최소인 (id, iq)를 고른다. 전류가 최소이면 동손이 최소에 가깝다.

**왜 "T 이상"만 보면 되는가.** 전류각 β를 고정하면 토크는 Is에 대해 증가한다(3절의 식, ΔL ≥ 0). 따라서 "T 이상을 내는 점 중 전류 최소"의 최소점은 토크가 정확히 T인 점이다. 그래서 속도마다 전압 제약을 만족하는 dq 격자점을 토크 순으로 정렬하고, "토크가 T 이상인 점들의 전류 최소값"을 뒤에서부터 누적 최소로 한 번에 구한다. 점마다 훑지 않으므로 빠르다.

**보정.** 격자점은 간격(Imax/400) 때문에 토크가 T보다 조금 크다. 그 점의 β 주변에서 "정확히 T를 내는 Is(β)"가 최소인 β를 찾는다. Is(β)는 이분법으로 구하고(토크가 Is에 대해 단조), 전압 제약을 어기면 비용을 무한대로 둔다. β 구간을 11점으로 나눠 최선점 주변으로 1/5씩 줄이는 과정을 10번 반복한다(구간이 5⁻¹⁰ ≈ 1e-7배). 전압 제약 경계에서는 경계에 닿는 실행 가능한 쪽으로 수렴한다.

**검증.** 스칼라 `optimal_current`는 β 격자 + 이분법으로 같은 문제를 푼다. 두 알고리즘이 독립이므로 테스트에서 서로 비교한다(상대 2e-3 이내).

## 11. 차량과 주행 사이클 전비 (M4, `engine/vehicle.py`)

**바퀴 힘.** 차량을 점 질량으로 보고 `F = m_eq·dv/dt + (A + B·v + C·v²)`이다. 괄호는 EPA 도로 부하 계수(공기저항·구름저항·구동계 끌림을 코스트다운으로 한꺼번에 잰 값, 힘 [lbf], 속도 [mph])를 SI로 바꾼 것이고, `m_eq`는 EPA 등가 시험 중량이다(동력계 관성 설정이라 회전 관성이 들어 있다). 기획서 5.5절의 `½ρC_dAv²`와 `m·g·C_rr` 항은 이 세 계수가 대신한다(공기와 구름을 따로 나눌 자료가 없다). 경사는 0이다.

**모터 동작점.** `ω_m = g·v`, `g = G/r_w`. ORNL TM-2006/423이 "모터 rpm = 60.66 × 차속 mph"라고 적었으므로 `g = 60.66·(π/30)/0.44704 = 14.21 rad/s per (m/s)`이다. 기어 무부하 손실 `L(ω_m)`(ORNL 표 3.7)을 더해 모터 축 동력 `P_s = F·v + L`을 얻는다. 구동(`P_s > 0`)에서는 `L`만큼 모터가 더 내고, 회생(`P_s < 0`)에서는 `|F·v| − L`만 모터 축이 받는다.

**전기 에너지.** 구동: 전자기 토크 `T_e = (P_s + P_mech)/ω_m`로 효율맵 `P_in(T_e, ω_m)`을 쌍선형 보간하고 `E_in = ∫P_in dt`. 회생: 축이 받는 동력 `P_g = r·|F·v| − L` (`r` = 회생 비율, 나머지는 마찰 제동), `T_e = (P_g − P_mech)/ω_m`, 전기 출력 `P_el = T_e·ω_m − 손실 = 2·T_e·ω_m − P_in(T_e, ω_m)`. IPM의 자기 회로는 d축에 대해 대칭(ψd는 iq의 짝함수, ψq는 홀함수)이라 같은 맵을 거울로 쓴다. 전비 = `주행 거리 / (E_in − E_regen)`.

**이산화.** 1 Hz 속도 표의 구간마다 평균 속도 `v̄`와 평균 가속도 `ā = Δv/Δt`로 동작점을 정하고 `Δt`를 곱해 더한다. 관성 일 `m·ā·v̄·Δt = ½·m·(v₁² − v₀²)`이 정확해 운동 에너지가 새지 않는다(점마다 중앙 차분을 쓰면 속도 꺾임점에서 5%가 새는 것을 테스트가 잡았다).

**모터가 낼 수 없는 토크.** 효율맵의 실행 가능 영역 밖이면 낼 수 있는 최대 토크로 자르고 못 낸 바퀴 에너지를 `shortfall`로 기록한다(숨기지 않는다). 회생에서 모터가 받을 수 있는 한계를 넘는 몫은 마찰 제동으로 돌린다.

**검증(테스트).** 손실 0, 도로 부하 0이면 가속에 쓴 운동 에너지를 감속 회생(r = 1)이 모두 되찾는다. 손실 0의 등속 주행은 전기 에너지가 도로 부하 일과 같다. 기어 손실 `L`은 구동 에너지를 `L·t`만큼 늘리고 회생을 같은 만큼 줄인다. `tests/test_p4_vehicle.py`.

**한계.** 모터 입력(교류) 기준이다. 인버터·배터리·보조 부하는 없다. 기어 손실은 무부하 값뿐이고(부하 의존 손실 자료 없음) 윤활유 25 °C 값이다(80 °C에서는 약 20% 작다). 실제 Prius는 엔진을 같이 쓰므로 이 전비는 순수 전기 구동 환산이다.

**3상 파형 (`engine/waveforms.py`).** 크기 불변 Park 변환의 역: `ia = id·cosθ − iq·sinθ`, `ib`, `ic`는 θ를 ∓120° 옮긴 식이다(전압도 같다). 한 전기 주기 파형의 진폭이 `|Is| = √(id² + iq²)`이고 세 상의 합이 0이며, 다시 Park 변환하면 처음 `(id, iq)`가 나온다(`tests/test_p4_waveforms.py`). 전류각은 `β = atan2(−id, iq)`로, MTPA에서는 0 < β < 90°이고 약계자일수록 크다.
