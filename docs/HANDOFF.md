# 인수인계 (claude.ai 대화 → Claude Code)

작성: 2026-11-22. 이 폴더는 claude.ai 대화에서 기획까지 마친 상태로 Claude Code에 넘어왔다. 코드는 아직 한 줄도 없다.

## 지금까지 정해진 것
- 주제: EV 구동용 IPMSM 설계 → 효율맵 → 주행사이클 전비 통합 해석 도구. 기존 `Gnho-UOU/motor-analyzer`(유도기 교육용 시뮬레이터, 계산 근거·검증 부족)를 대체하는 새 프로젝트. motor-analyzer는 수정하지 않는다.
- 계산은 순수 Python 엔진, UI는 이후에 붙인다. 검증 통과 전 UI 확장 금지.
- 필수 범위 M1~M4(모터 모델, 운전 영역, 손실·효율맵, 주행사이클 전비). 확장 M5~M8은 순서대로.
- 최종 검증 기준: ORNL 프리우스 2004 구동모터(형상 보고서 ORNL/TM-2004/137 + 효율맵 측정 보고서). 이 모터는 "엔진 정답지"이고 설계 대상은 아니다. 설계 대상은 엔진 검증 후 현대 BEV급 사양으로 따로 정한다.
- FEA는 FEMM 4.2 + pyfemm. FEMM이 Windows 전용이라, Windows PC에서 `run_femm.bat` 더블클릭 한 번으로 계산 → CSV 저장 → GitHub 푸시까지 자동화한다(방법 1). 최적화 단계(M6)에서는 공유 폴더를 감시하는 작업 대기 모드(방법 2)를 검토한다.
- JMAG 등 상용 툴 리버싱은 하지 않는다. 나중에 연구실 라이선스를 쓸 수 있도록 FEA 부분은 교체 가능한 구조로 둔다.
- 일정(기획서 9장): P0 문헌·환경 준비(~12/6) → P1 엔진 코어 M1·M2(~1/3) → P2 손실·효율맵(~1/24) → P3 FEMM 연동·검증(~2/28) → G1 검증 관문 → P4 전비·UI 연결(~3/28) → 3/31 연구실 컨택 → P5 확장 → P6 정리.

## 2026-11-22 해결: 전체 모터 모델과 Br 보정
- **AGE 회전 문제는 다른 방법으로 해결했다.** 대칭 섹터·AGE 대신 전체 모터(360°, 48슬롯, 8극)를 공극까지 메시로 만들고 회전자를 기하학적으로 돌린다(`femm/prius_full.py`, `femm/validate_full.py`). 무부하 위상 오차 ≤ 0.7°, `λ(45°) = −λ(0)` 정확, 코깅 ±0.25 N·m. 점당 약 76초(8개 병렬). 원인(xfemm AGE의 어디가 틀렸는지)은 여전히 모른다. 자세한 내용은 `docs/FEA_OPTIONS.md` 3-3절.
- 스마트 메시가 기본 켜짐이고 xfemm Lua에 끌 명령이 없다. 저장한 `.fem`에 `[DoSmartMesh] = 0`을 넣으면 요소가 절반이 된다.
- **ORNL 잠금 토크 시험 모사:** 전류별 최대 토크가 실측(Fig. 3.10)의 0.99~1.09배, 토크-각도 곡선 7개가 영점 하나(와 거울 방향 가정)로 모두 맞는다(상관계수 0.991~0.996).
- **Br 보정(`1.24 → 1.056 T`)은 무부하 역기전력에만 맞췄고**, 독립 검증이 통과했다: 저속 필요 전류 엔진/측정 0.99(0.96~1.03), 250 A 잠금 토크 337 N·m(실측 337). 맵: `data/flux_maps/prius2004_fullmodel_Br1056_25A.csv`.
- **해결하지 못한 것(`docs/FEA_OPTIONS.md` 3-4절):** (1) 고속(> 2400 rpm) 필요 전류가 측정의 0.61~0.94배(중앙 0.72). 측정 전압이 육각파 한계에 있어 전압 가정은 원인이 아니고, 후보는 고속(큰 |id|)에서의 FEA d·q 자속 특성(교차 포화, 엔드턴 누설, 3D)이지만 확인하지 못했다. (2) 75 A 잠금 토크가 실측보다 13% 낮다. (3) AGE 오차의 원인.
- 다음 후보: 엔드턴 누설 인덕턴스 추정(해석식, 출처 필요), 맵 해상도(25 A → 12.5 A)와 메시 수렴, 상저항·철손을 넣은 효율맵(P2)과 ORNL 모터 효율 비교, 진짜 FEMM에서 같은 모델 교차 검증.

## 2026-11-22 P3 진행 (FEA 자속 맵)
- Prius 1극 섹터 FEA 모델을 만들어 xfemm으로 풀었다(`femm/prius_sector.py`, `prius_run.py`, `make_flux_map.py`). 형상·재료는 제3자 값(`data/benchmarks/prius2004_geometry.json`).
- **xfemm AGE 회전은 큰 각도에서 부정확**하다(δ = 45°에서 진폭 절반, 원인 미규명). 그래서 자속 맵은 회전자 위치 δ = 0 한 곳에서 전류 벡터만 바꿔 만든다. 회전이 필요한 비교(ORNL Table 3.2 잠금 토크-각도, 토크 맥동, 위치 평균)는 진짜 FEMM이 있어야 한다. 자세한 내용과 고친 오류는 `docs/FEA_OPTIONS.md` 3-2절.
- 무부하 자속 진폭이 ORNL 환산값(0.174 Wb)보다 약 20% 크다. 이후 `Br`만 1.056 T로 보정하는 프로토콜을 썼다(아래 "2026-11-22 해결" 절).
- 자속 맵 121점을 만들었다(`data/flux_maps/prius2004_xfemm_delta0_25A.csv`, 25 A 간격, 약 8분). `FluxMapModel`로 읽어 엔진에 넣고 ORNL 실측과 **예비 비교**를 했다(`tests/test_v4_prelim_prius.py`, 계수 조정 없음):
  - 250 A MTPA 토크 362 N·m, 150 A에서 227 N·m: 실측 범위(337~400, 221~260) 안. 75 A에서는 109 N·m로 실측(118~140)보다 8~22% 낮다.
  - Table B-1 운전점에서 엔진이 예측한 필요 전류 / 측정 전류(실효값 × √2): 속도 ≤ 1900 rpm의 11점(토크 60~282 N·m)에서 **0.91~0.98**. 속도 > 2500 rpm에서는 **0.63~0.82**로 엔진이 전류를 적게 예측한다(Rs = 0, 철손 없음, 실제 DC 전압 강하 등 때문일 수 있으나 확인하지 못했다).
  - 무부하 자속은 ORNL 환산값보다 +21% 큰데 250 A 토크는 실측 범위 안이다. 이 둘이 서로 상쇄되었을 가능성이 있어 "검증 통과"라고 하지 않는다.
  - 비교 한계: 측정 전류의 상/선·첨두/실효 정의가 보고서에 없어 "상 실효값"으로 가정했다. 형상·자석·철심은 제3자 값이다. 상저항을 몰라 Rs = 0으로 했다. 맵은 회전자 한 위치(δ = 0)와 25 A 간격 선형 보간이다.
- 다음: 맵 해상도(25 A → 더 촘촘히)와 메시 수렴 확인, 상저항·철손을 넣은 효율맵(P2 `efficiency_map`)을 ORNL Table B-1의 모터 효율과 비교, 자석 Br 민감도(보정이 아니라 민감도 분석).
