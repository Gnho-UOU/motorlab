# FEA 실행 환경 조사 (Mac에서 FEMM을 못 쓰는 문제)

2026-11-22 조사. 문제: FEMM은 Windows 전용이고, 사용자는 Windows PC 사정을 모른다. 이 문서는 대안 후보를 **확인한 것**과 **확인하지 못한 것**으로 나눠 기록한다.

## 1. 이 Mac의 환경 (직접 확인)

Intel Core i9-9880H, RAM 16 GB, macOS 15.7.1, 디스크 여유 약 380 GB. Xcode(clang, make)는 있다. cmake, Homebrew, Docker, Wine, 가상화 앱(Parallels·VMware·VirtualBox·UTM), Gmsh, Elmer는 없다. **Intel이라 x86 Windows VM이나 Wine이 에뮬레이션 없이 돈다.**

## 3. 권고

**1순위: xfemm `femmcli`를 이 Mac에서 직접 빌드해 쓴다.** 이유: (a) 네이티브라 VM·Windows가 필요 없다. (b) 입력이 FEMM의 Lua 명령 그대로라서, 같은 `.lua` 스크립트를 나중에 진짜 FEMM(연구실·Windows)에서도 돌려 **솔버 교차 검증**을 할 수 있다. (c) `CLAUDE.md`의 "FEMM은 분리" 규칙이 그대로 유지된다: 스크립트가 CSV만 남기고 `engine/`은 CSV만 읽는다.

**타당성 시험은 통과했다(아래 3-1). 다음은 P3 형상(`data/benchmarks/prius2004_ornl.md` 7절)으로 올라가는 것이다.** 문제가 생기면 2순위 GitHub Actions Windows 러너(비용 없음, 가장 간단한 시험부터), 3순위 Windows VM.

### 3-1. 타당성 시험 결과 (2026-11-22, 이 Mac, xfemm 커밋 `132515c`)

**빌드:** 성공. 단 **업스트림 그대로는 실패한다.** Apple clang 17(libc++)에서 세 가지가 컴파일되지 않아 13줄을 고쳤다: (1) `sincos()`는 GNU 확장(`femmcomplex.cpp`), (2) `std::ptr_fun`은 C++17에서 제거(`stringTools.h`; 프로젝트는 C++17을 지정하면서 GNU libstdc++에서만 통하는 코드를 쓴다), (3) `<malloc.h>`가 macOS에 없음(10개 파일). 수정은 `femm/build_xfemm_macos.sh`가 자동으로 적용한다(새 소스에서 63초, 이 스크립트로 처음부터 다시 빌드해 확인함). 패치는 GPL 파생물이라 저장소에 두지 않았다. 업스트림에 알리지는 않았다. CMake가 설정 중에 `github.com/dcm3c/tangle`(Tangle 메시 생성기)을 추가로 내려받는다.

**저장소 자체 테스트(`ctest`):** 55개 중 54개 통과(순차 실행). 실패 1건(`femmcli_femfile.check.ans`)은 검증 스크립트의 정규식 버그다. CMake 따옴표 안의 `\[`가 `[`로 처리돼 `^[Solution]$`가 되기 때문이고, 정규식을 고쳐 같은 파일을 검사하면 통과한다(파일에는 `[Solution]` 섹션이 있다). 열 해석 `hsolver_Temp1`은 병렬(-j4) 실행에서만 한 번 segfault했고 순차에서는 통과했다(자기 해석과 무관). 5개는 저장소가 비활성화해 둔 것이다.

**수치 정확도:**
- FEMM 위키 토크 벤치마크(저장소 테스트): 해석해 토크와 상대 오차 0.006% 이내, 이 Mac에서 통과.
- 직접 만든 해석해 시험 `femm/validation/run_checks.py`(21초, 진짜 FEMM에서도 같은 `.lua`를 돌릴 수 있다):

| 시험 | 해석해 | 결과 |
| --- | --- | --- |
| 선형: 균일장 속 원통(μr=10) | `Bx = 2μr/(μr+1)·B0` | 공기 메시 10 mm → 2 mm에서 오차 −0.85% → −0.34% |
| 영구자석: 균일 자화 원통(μr=1) | `Bx = (Br/2)(1 − (R/Rfar)²)` | 같은 메시에서 −0.96% → −0.31% (공기 메시를 1 mm로 줄이면 −0.13%) |
| 비선형 BH: 전류선 둘레 강판 원통(포화 포함) | `B = f(I/2πr)` | 최대 오차 0.37% (I = 300 A, 3000 A) |

**교훈(V3에 적용):** 공기 영역 메시가 거칠면 1차 요소 때문에 영구자석·선형 문제도 −1%대 오차가 남는다. 메시를 촘촘히 하면 단조롭게 해석해로 수렴한다(처음에 영구자석 −1.2%를 솔버 문제로 의심했으나 이산화 오차였다). 그래서 V3에서는 공극 주변 메시를 충분히 촘촘히 하고 **메시 수렴을 확인**한다.

**시험하지 않은 것:** xfemm의 Python 인터페이스(`FemmSession`), 진짜 FEMM과의 직접 비교.

### 3-2. Prius 섹터 모델과 AGE 회전 한계 (2026-11-22)

코드: `femm/prius_sector.py`(형상 생성, pyleecan `SlotW11`·`HoleM50` 점 좌표 공식을 옮김), `femm/prius_run.py`(실행·Park 변환), `femm/make_flux_map.py`(자속 맵 CSV). 형상·재료 값은 `data/benchmarks/prius2004_geometry.json`(제3자, 미검증).

**확인된 것:**
- 형상을 그려서 눈으로 확인했다(슬롯 6개 반원 바닥, V자 자석 2개, 끝 공극, 권선 라벨 A+ A+ C− C− B+ B+).
- 무부하에서 회전자 표면의 반지름 방향 자속이 6°~39°에서 양수이고 중심이 22.5°라서 극 위치가 맞다.
- 무부하 쇄교자속의 위상은 d축이 A상 축에서 **150.0°** 앞서 있다. 코일 중심으로 유도한 값(`4·(22.5° − (−15°))`)과 같다.
- 2극(90°) 주기 모델에서 `θr = 0`과 `θr = 90°`, `45°`와 `−45°`가 정확히 같다(주기성).
- 부하 상태 쇄교자속은 그럴듯하다: `(id, iq) = (0, 50) A`에서 `ψq = 0.184 Wb`(Lq ≈ 3.7 mH, ORNL 정적 측정 5 mH와 같은 자릿수), 전류가 커지면 포화로 감소.

**처음에 틀렸다가 고친 것:**
1. A상 자기축을 벨트 중심(7.5°)으로 가정했다. 쇄교자속이 최대가 되는 축은 코일 중심이다(전절 코일 중심 30°, 부호가 반대인 쪽이 양의 축이라 −15°). `θ0`을 60°에서 150°로 고쳤다.
2. `mo_gapintegral`이 이미 전체 360° 토크를 돌려주는데 극 수 8을 곱했다. 자속 기반 토크와 0.1% 이내로 일치하는 점으로 바로잡았다.
3. AGE 각도를 안쪽·바깥쪽 모두 0으로 두면 거울 대칭이 요구하는 값(코깅 0)이 나오지 않았다. 바깥쪽에 기준각 22.5°, 안쪽에 `기준각 + θr`을 주면 정확히 나온다.

**해결하지 못한 문제 — xfemm AGE 회전은 큰 각도에서 부정확하다:**

| 상대 회전 δ | 기대 위상 | 측정 위상 | `\|ψ\|` |
| --- | --- | --- | --- |
| 0° | 150° | 150.0° | 0.2101 |
| 10° | −170° | −172.4° | 0.2067 |
| 22.5° | −120° | −147.3° | 0.1993, 코깅 −207 N·m |
| 45° | −30° | −35.7° | **0.1097** |

대칭상 δ = 45°(극 하나 이동)는 δ = 0의 부호만 뒤집은 상태여야 하는데 진폭이 절반으로 줄었다. 호 분할을 0.25° → 0.1°로 촘촘히 해도, 안쪽 각도 대신 바깥쪽 각도(반대 부호)를 써도, 1극 반대칭이든 2극 주기 모델이든 같다. xfemm 자체의 AGE 벤치마크(단순 형상)는 해석해와 0.0055% 이내로 맞는데 이 모델에서만 어긋나는 원인은 밝히지 못했다. 신뢰할 수 있는 범위는 대략 |δ| ≲ 10°이다.

**우회와 영향:**
- 자속 맵은 **회전자를 기준 위치(δ = 0)에 고정하고 전류 벡터(id, iq)만 바꿔서** 만든다. 무부하 ψd의 위치별 변동은 ±1%다.
- AGE 토크는 δ에 대해 체계적으로 변한다(180 → 44 N·m). 자속 기반 토크는 매끈하다(148~172 N·m). 그래서 **엔진의 토크는 자속에서 계산하고 AGE 토크는 비교용으로만 CSV에 남긴다.** δ = 0에서 둘의 차이는 −9%~+22%이다.
- 회전자 위치를 바꿔야 하는 비교(ORNL Table 3.2 잠금 토크-각도 곡선, 위치 평균, 토크 맥동)는 이 도구로 할 수 없다. 진짜 FEMM이 필요하다.

**무부하 자속 진폭이 ORNL 환산값보다 크다:** FEA의 `|ψ|`는 약 0.207~0.210 Wb이고 ORNL 역기전력 상수에서 환산한 값은 0.174 Wb(`data/benchmarks/prius2004_ornl.md` 4절)로 **약 +20%**다. 원인 후보는 자석 Br = 1.24 T 가정(출처 없음), 2D 해석(엔드 효과 없음), 자석 온도(20 °C 가정), 철심 재질(M400-50A 대 M19)이다. **보정하지 않았다.** V4에서 이 차이를 그대로 보고하고, 보정한다면 Br만 조정하고 그 사실을 명시한다.

### 3-3. 해결: 전체 모터 모델(공극 메시)로 회전을 다룬다 (2026-11-22)

3-2절의 AGE 회전 문제는 **원인을 밝히지 못한 채 다른 방법으로 풀었다.** 대칭 섹터와 AGE를 쓰지 않고 전체 모터(360°, 48슬롯, 8극)를 공극까지 메시로 만들어 회전자를 기하학적으로 돌린다(`femm/prius_full.py`). 토크는 회전자 블록(철심·자석·공기 포켓·공극 안쪽 층)의 Henrotte 응력 적분(`mo_blockintegral(22)`)으로 구하고, 쇄교자속은 상 회로에서 바로 읽는다(배율 없음). 점마다 모델을 새로 만들어 독립 프로세스로 8개씩 병렬 실행한다.

**AGE가 실패한 검사를 통과한다 (무부하, 전체 모델):**

| 항목 | AGE 섹터 | 전체 모델 |
| --- | --- | --- |
| 위상 오차 (θr = 22.5°) | −27° | 0.4° (0~22.5° 전 구간 ≤ 0.7°) |
| `\|ψ\|` (θr = 45°) | 0.110 (절반) | 0.208 |
| `λ(45°)` 대 `−λ(0)` | 불일치 | 정확히 일치 `(0.1803, −0.1803, 0)` |
| 무부하 코깅 토크 | ±300 N·m | ±0.25 N·m |

**메시에 관해 알아낸 것:**
- xfemm Lua에는 `smartmesh` 명령이 없고(소스에서 주석 처리) 스마트 메시가 기본 켜짐이다. 가까운 꼭짓점 간격에 맞춰 요소를 잘게 만들어 이 모델은 요소가 22.5만 개다. 저장한 `.fem`에 `[DoSmartMesh] = 0` 줄을 넣으면 꺼져 11.2만 개가 된다(물리 결과는 같다: `|ψ| = 0.2082`, `θ = 150.0°`). `prius_full.solve_one`이 모델 저장 → 줄 삽입 → 다시 열어 풀기의 2단계로 처리한다.
- 요소 크기 설정(블록·호 분할)을 2배로 키워도 요소 수는 7%밖에 안 줄었다. 48슬롯, 8극, 0.75 mm 공극, 1.5 mm 브리지의 경계 분할이 밀도를 정한다. 한 점에 약 76초, 8개 병렬로 실효 약 22초다.

**기존 AGE 자속 맵 교차 검증 (12점, `data/fea/prius2004_crosscheck_age_vs_full.csv`):** AGE 맵(δ = 0)과 전체 모델이 `ψq`는 −3.0~−0.2%(중앙 −0.5%), `ψd`는 절대 차이가 대부분 0.001~0.004 Wb, 최대 0.0068 Wb(`ψm`의 3%, id = −250 A)다. `ψd`가 0에 가까운 점에서는 백분율이 크게 나온다(−18.7%). AGE 맵은 쓸 만하지만 전체 모델이 더 믿을 수 있다.

**ORNL 잠금 회전자 시험 모사 (112점, `data/fea/prius2004_full_locked_torque.csv`):** ORNL처럼 상전류 `(Ia, −Ia/2, −Ia/2)` 직류를 고정하고 회전자 각도를 돌려 토크-각도 곡선을 구했다(회전자 0~56.25°, 3.75° 간격, 전류 7개).
- **전류별 최대 토크**(FEA / TM-423 Fig. 3.10): 50 A 1.09, 75 A 1.04, 100 A 1.05, 125 A 0.99, 150 A 1.04, 200 A 1.02, 250 A 1.07. 중앙 1.04, 범위 0.99~1.09. 250 A에서 FEA 362 N·m, 실측 337(2005년 시험)~400(2004년 시험).
- **곡선 모양:** ORNL 각도 원점을 모르므로 영점 `c`를 하나 두고 250 A 곡선에서만 맞췄다(`c = 143.2°`). 같은 방향으로는 맞지 않고(RMS 197.5 N·m, 최대의 58%) **ORNL 각도가 FEA 회전 방향과 반대라고 가정해야** 맞는다(RMS 23.6 N·m, 7%). 그 `c` 하나로 나머지 6개 전류 곡선도 모두 맞는다: 상관계수 0.991~0.996, RMS 6.7~9.3%, 정점 각도 실측 120~126° 대 FEA 120.4~127.6°. 영점과 방향만 자유 변수이고 전류별 곡선은 독립 확인이다. 거울 방향은 ORNL 보고서에 적혀 있지 않은 가정이다. 회귀 테스트 `tests/test_v4_prelim_prius.py`.

**전체 모델 자속 맵 (`data/flux_maps/prius2004_fullmodel_25A.csv`, 25 A 간격 121점, 회전자 0°·3.75° 두 위치 평균, 54분):**

- 자속 기반 토크와 두 위치 평균 Henrotte 토크의 차이: 중앙 −2.6%, 범위 −6~+6%. AGE 단일 위치는 중앙 +7.8%, ±22%였다. 슬롯 주기 절반 간격의 두 위치를 평균하면 슬롯 맥동의 기본 성분이 상쇄된다.

**남은 한계:** 한 점에 약 76초라 해상도를 높이기는 비싸다. 2D 해석이라 엔드턴 누설이 없다. 형상·자석·철심은 제3자 값이고 무부하 자속 +21% 문제는 그대로다(250 A 토크 비 1.07과 함께 보면 자속이 큰 만큼 포화·누설이 다른 방향으로 상쇄하고 있을 가능성이 있으나 확인하지 못했다).

### 3-4. 자석 Br 보정과 독립 검증, 그리고 해결하지 못한 것 (2026-11-22)

무부하 쇄교자속이 ORNL 환산값(0.174 Wb)보다 약 20% 크다는 문제(3-2절)에 대해, **자석 Br만** 무부하 역기전력에 맞추고 그 결과를 보정에 쓰지 않은 다른 실측으로 검증했다. 보정값은 `Br = 1.056 T`(제3자 값 1.24 T가 아니다)다. `|ψ|`가 `Br`에 선형이라(1.00 T → 0.1630 Wb, 1.06 T → 0.1746 Wb) 한 번에 구했다. 보정한 맵은 `data/flux_maps/prius2004_fullmodel_Br1056_25A.csv`이고 머리 주석에 보정값임을 적었다. 보정의 근거 자체가 가정에 기댄다: ORNL의 Vrms가 선간 실효값이라는 해석(`data/benchmarks/prius2004_ornl.md` 4절).

**보정 전후 비교 (엔진에 맵을 넣은 결과, 조정한 다른 계수는 없다):**

**독립 검증된 것:** 저속 필요 전류가 보정 후 사실상 정확하고(0.96~1.03), 250 A 잠금 토크가 실측 337 N·m와 일치한다. 이 두 값은 보정에 쓰이지 않았다.

**맞지 않는 것:**
1. **고속(> 2400 rpm) 필요 전류**는 보정과 무관하게 측정의 0.61~0.94배다(중앙 0.72). 엔진이 전류를 적게 예측한다.
2. **저전류 토크:** 75 A에서 103 N·m로 실측 하한(118)보다 13% 낮다. 150 A는 1.4% 낮다(보정 전에는 범위 안이었다).

**고속 불일치의 원인을 가려 본 것:** (a) 전압 한계 가정은 원인이 아니다. TM-423 Table B-1의 `Vac_rms_V` 열은 고속 모든 점에서 239~241 V로 포화한다. 이는 육각파 운전의 상전압 총 실효값 `(√2/3)·Vdc = 235.7~238 V`와 일치한다(그래서 이 열은 선간이 아니라 상전압의 총 실효값이고 고조파를 포함한다). 육각파 기본파 상 첨두는 `2·Vdc/π = 318 V`이고 엔진도 그 점들에서 `|v| = 318.3 V`로 전압 한계에 걸리므로 `k_mod = 2/π` 가정은 맞다. (b) 상저항·철손은 무시했지만 철손 전류 성분은 많아야 7 A 정도라 52 A 차이(4204 rpm, 89 N·m)를 설명하지 못한다. (c) 자석 온도는 `Br`을 바꿔도 변하지 않는 것으로 보아 원인이 아니다. **남은 후보는 고속(큰 `|id|`)에서 FEA의 d·q 자속 특성이 실제와 다른 것**(교차 포화, 엔드턴 누설 인덕턴스 없음, 3D 효과)이지만 이 환경에서는 확인하지 못했다. 미해결이다.

**측정 전류의 정의:** Table B-1의 `Iac_rms_A`도 같은 방식으로 총 실효값(고조파 포함)일 가능성이 크다. 이 비교는 엔진의 기본파 전류 첨두를 `Iac_rms × √2`와 비교한 것이다.

### 3-5. 수치 수렴과 Br 보정의 타당성 (2026-11-22)

**메시 수렴.** 전체 모델(공극 메시, 스마트 메시 끔)을 메시 4종으로 풀었다(`Br = 1.056 T`, 회전자 0°). 무부하와 부하점 `(id, iq) = (−100, 150) A`:

| 메시 | 요소 수 | 무부하 `ψd` | 부하 `ψd` | 부하 `ψq` | 부하 자속 토크 |
| --- | --- | --- | --- | --- | --- |
| 거침 (크기 ×2, 호 1.0°) | 103,580 | 0.17386 Wb | 0.04817 Wb | 0.33729 Wb | 245.73 N·m |
| 기준 (맵에 쓴 메시) | 111,733 | 0.17387 | 0.04794 | 0.33759 | 245.70 |
| 촘촘 (크기 ×0.67) | 128,236 | 0.17396 | 0.04791 | 0.33785 | 245.83 |
| 더 촘촘 (크기 ×0.5, 호 0.25°) | 167,895 | 0.17396 | 0.04788 | 0.33796 | 245.87 |

기준 메시와 가장 촘촘한 메시의 차이는 `ψd` −0.05%(무부하)/+0.13%(부하), `ψq` −0.11%, 토크 −0.07%다. 거친 메시도 부하 `ψd`가 0.6% 안이다. **자속 맵의 이산화 오차는 약 0.1%로, ORNL 실측과의 차이(토크 수 %, 효율 3~9%p)보다 훨씬 작다. 남은 차이는 모델 오차다.** 점당 시간은 요소 수에 거의 비례해 늘어 가장 촘촘한 메시는 약 3분이다.

**`Br` 보정이 기대는 해석의 타당성.** `Br` 보정은 ORNL의 역기전력 `Vrms`가 선간 실효값이라는 해석(`data/benchmarks/prius2004_ornl.md` 4절)에 기댄다. 상전압이라고 읽으면 `ψm = 0.303 Wb`이다. 무부하 자속이 `Br`에 선형이라(1.24 T에서 0.209 Wb) 이 값을 내려면 `Br ≈ 1.24 × 0.303/0.209 = 1.80 T`가 필요한데, 소결 NdFeB의 잔류자속밀도 상한(약 1.4~1.5 T)을 넘어 물리적으로 불가능하다. 따라서 선간 실효값 해석이 유일하게 가능하다. 이것은 가정의 가능성을 하나 지운 것이지 `ψm = 0.174 Wb`가 정확하다는 증명은 아니다(자석 온도 20 °C, 2D 해석, 철심 값이 제3자 값).

**동작점 선택(`objective="loss"`).** 시험 제어기가 효율이 가장 높은 점을 골랐다는 점을 반영해 `optimal_current`에 `loss_fn`을 받는 `objective="loss"`를 구현했다(독립 격자 전수 탐색과 비교해 검증). 효율 오차의 원인이 아님을 확인했다(`docs/validation_report.md`).

### 3-6. ORNL 해체 측정으로 입력을 바꾸고 Br 교정을 독립 측정 세 개로 확인했다 (2026-11-22)

**1) 입력을 ORNL 해체 측정과 대조했다.** TM-2010/253(2004 Prius 해체 측정, 본문 45쪽·표 2.7)이 pyleecan 값과 같다: 자석 83.1 × 18.9 × **6.5 mm**(77 g), 슬롯 개구 1.93 mm, 48슬롯, 코일당 9턴. 다른 값은 ORNL 쪽으로 바꿨다: 공극 0.73025 mm(pyleecan 0.75), 적층 길이 83.6 mm(pyleecan 83.82), 회전자 반지름 80.19 mm, 자석 투자율 1.129(그림 14 측정). 형상 파일 `prius2004_geometry_teardown.json`. 상 저항은 측정값 0.069 Ω(21 °C)을 쓴다(효율 표에서 역산한 65 mΩ과 6% 안에서 일치).

**2) 측정한 자석 곡선 Br 1.243 T를 그대로 쓰면 자속이 약 20% 크다. 독립 측정 세 개가 같은 값을 가리켰다.** 무부하 역기전력 환산 0.174 Wb, 공극 자속밀도(TM-137 그림 13)의 측정/FEA 크기비 0.839, 잠금 토크 50·75 A의 PM 성분에서 구한 등가 자속 0.175·0.177 Wb. 그림 13은 파형 모양이 크기를 자유롭게 두면 최대값의 약 4% RMS로 맞아서 극 폭·형상은 맞고 크기만 어긋난다. 따라서 "자석이 모터 안에서 시료 곡선보다 약 15% 약하다"는 결론이 역기전력 해석(선간 실효값이라는 가정)에 의존하지 않는다. 약해지는 원인은 확인하지 못했다(시료 곡선의 시험 온도 불명, 착자 상태, 3D 효과가 후보). Br 1.06 T로 교정하면 무부하 0.174 Wb, 공극 B 크기비 1.007, 75 A 잠금 토크의 PM 등가 자속 0.1756 Wb(측정 0.1769)이다. 높은 전류에서는 PM 성분이 측정보다 작아진다(150 A 0.167 대 0.176, 250 A 0.151 대 0.163; 아래 4)).

## 4. 검증 방침 (솔버 신뢰도)

xfemm이 FEMM과 같은 값을 낸다는 자료를 못 찾았으므로, **xfemm 결과를 그대로 믿지 않는다.** V3에서 (1) 해석해 문제, (2) ORNL TM-423의 실측 역기전력(Table 3.4)·잠금 토크(Table 3.2), (3) 가능하면 진짜 FEMM에서 같은 `.lua`를 돌린 결과와 비교한다. 차이는 보고서에 그대로 적는다.

## 5. 라이선스 메모

xfemm은 GPL-3.0이다. 이 프로젝트는 xfemm을 외부 프로그램으로 실행만 하고 링크하지 않는다. 재료 라이브러리 `matlib.dat`(FEMM 배포 파일)의 재배포 조건은 공개 전에 확인한다.

## 6. 아직 모르는 것

- xfemm과 진짜 FEMM의 직접 수치 차이(해석해 시험으로만 확인했다. 같은 `.lua`를 진짜 FEMM에서 돌려 비교하는 것은 아직).
- 실제 전동기 규모 모델(영구자석 + 포화 강판 + 슬롯)의 계산 시간. 자속 맵 한 장에 필요한 (id, iq) 점 수와 회전자 위치 수를 곱하면 해석 횟수가 커질 수 있다.
- FEMM 명령줄 Lua 옵션(`-lua-script`)과 Wine·macOS 조합, FEMM이 GitHub Actions 러너에서 시작되는지(대안 경로, 필요해질 때만).
