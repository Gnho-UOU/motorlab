1.   개요
전기차 구동용 매입형 영구자석 동기전동기(IPMSM)를 한 흐름으로 계산하는 도구를 만듭니다. 설계 변
수에서 출발해 dq 파라미터, 운전 영역(MTPA·약계자), 효율맵을 거쳐 주행사이클 전비까지 이어지고,
결과는 3D 모델 위에서 보여 줍니다. 계산은 전부 Python 엔진이 맡고, 결과는 공개 데이터와 유한요소
해석(FEA) 결과로 검증합니다.
가칭: Motor Lab — EV 구동모터 설계·효율·전비 통합 해석 도구
왜 다시 만드나. 이전 프로젝트 motor-analyzer(유도전동기 교육용 시뮬레이터)에는 네 가지 한계가 있
었습니다.
   계산 근거가 흐립니다. 토크 보정계수(0.2–5배)나 기동 전류 배율 같은 임의 값이 들어가 있습니다.
   계산이 JS 코드 안에 흩어져 있어 무겁고, 고치기 어렵습니다.
   테스트와 검증 자료가 없어 결과가 맞는지 보여 줄 수 없습니다.
   계획 없이 기능을 덧붙여 주제가 흐려졌습니다.
이번 원칙. 계산 엔진을 먼저 만들고, 검증을 통과한 뒤에 화면을 붙입니다. 모든 수식은 문헌 근거를 달고,
모든 그래프는 스크립트로 다시 만들 수 있어야 합니다.
왜 PMSM인가. 전기차 구동모터의 주류가 영구자석 동기전동기이고, 목표 연구실 두 곳의 연구 키워드
(구동모터 설계, 영구자석, 효율, 주행사이클, 최적화)가 이 주제에 모여 있습니다.

최종 산출물: GitHub 저장소(Python 엔진, 테스트, 검증 노트북), 웹 3D 데모, 검증 보고서, 컨택용 2쪽
요약.
2.   목표 연구실과 주제 연결
두 연구실은 모두 ‘영구자석 전동기의 설계·효율 평가·최적화’를 다룹니다. 그래서 효율맵과 최적화를 프
로젝트의 중심에 둡니다.

5.   계산 모델과 수식
모든 계산은 정상상태 dq 모델 하나에서 출발합니다. 크기 불변 변환(전류 진폭 = dq 벡터 크기)을 쓰고,
변수 정의는 코드의 docstring과 같게 맞춥니다.

5.1    자속과 전압 (M1)
1단계는 상수 파라미터입니다.
    \psi_d = L_d i_d + \psi_m, \qquad \psi_q = L_q i_q


2단계는 FEA로 구한 맵 ψd(id, iq), ψq(id, iq)를 보간해 씁니다. 포화와 d·q축 교차결합이 자연스럽게
들어갑니다.
    v_d = R_s i_d - \omega_e \psi_q, \qquad v_q = R_s i_q + \omega_e \psi_d,
    \qquad \omega_e = p\,\omega_m



5.2    토크
    T_e = \tfrac{3}{2} p \left( \psi_d i_q - \psi_q i_d \right) = \tfrac{3}{2} p
    \left( \psi_m i_q + (L_d - L_q) i_d i_q \right)


IPMSM      은 Ld < Lq이므로 음의 id가 릴럭턴스 토크를 더합니다. p는 극쌍 수입니다.
5.3    운전 제한과 전류 궁적 (M2)
    i_d^2 + i_q^2 \le I_{max}^2, \qquad v_d^2 + v_q^2 \le V_{max}^2, \quad
    V_{max} = \frac{V_{dc}}{\sqrt{3}}


Vmax는 선형 변조 영역의 한계이며, 과변조 여유율은 설정값으로 둡니다. 상수 파라미터일 때 MTPA 조
건은 다음과 같습니다.
    i_d^{MTPA} = \frac{\psi_m - \sqrt{\psi_m^2 + 8 (L_q - L_d)^2 I_s^2}}{4 (L_q -
    L_d)}


맵 기반 모델에서는 해석해가 없으므로, 각 (토크, 속도) 점마다 ‘제약을 만족하면서 전류 크기(또는 전체
손실)를 최소화하는 (id, iq)’를 수치로 찾습니다. 방법은 dq 격자 전수 탐색(NumPy 벡터화) 후 국소 보
정입니다. 이전 3D 초안의 격자 탐색 로직을 Python으로 옮겨 시작점으로 씁니다.
5.4    손실과 효율 (M3)
    P_{cu} = \tfrac{3}{2} R_s(T)\,(i_d^2 + i_q^2), \qquad R_s(T) = R_{20}\left(1
    + \alpha_{cu}(T - 20)\right)


교류 저항(표피·근접 효과)은 주파수에 따른 계수 k_ac(f)로 근사하고, 헤어핀 권선은 확장에서 다룹니
다.
                                      치
    P_{fe} = \sum_{k \in \{\text{ },\,\text{요크}\}} m_k \left( k_h f B_k^{\beta}
    + k_e f^2 B_k^2 \right)

자속밀도 B_k는 치와 요크에서 ψd, ψq로 추정하고(2단계에서는 FEA 값 사용), 계수 kh, ke, β는 전기
강판 데이터시트에서 맞춥니다. 기계손은 Pmech = aω + bω³ 형태의 경험식을 씁니다.
  \eta = \frac{T_e \omega_m - P_{mech}}{T_e \omega_m + P_{cu} + P_{fe}}


철손을 토크 계산에 따로 반영할지(등가 철손 저항 모델)는 1단계에서는 생략하고, 검증 오차를 본 뒤 결
정합니다.
5.5    차량과 전비 (M4)
  F_{trac} = m_{eq}\frac{dv}{dt} + \tfrac{1}{2}\rho C_d A v^2 + m g
  C_{rr}\cos\theta + m g \sin\theta


  T_m = \frac{F_{trac}\, r_w}{G\,\eta_{gear}^{\pm 1}}, \qquad \omega_m =
  \frac{G\,v}{r_w}


모터 동작점마다 효율맵을 보간해 전기 입력을 구하고, 사이클 전체를 적분합니다. 회생제동 구간은 효율
을 반대로 곱하고, 회생 비율은 설정값입니다.
  E = \int \frac{T_m \omega_m}{\eta^{\,\mathrm{sgn}(T_m \omega_m)}}\,dt, \qquad
  \text{     전비} = \frac{\text{주행거리}}{E}\ [\mathrm{km/kWh}]

5.6    감자 검토 (M5)
자석 작동점의 자계가 해당 온도의 무릎점(knee point)보다 약해지지 않는지 확인합니다. 1단계는 자기
등가회로로 어림하고, 최악 조건(최고 온도, 최대 -id)은 FEA로 확인합니다. 페라이트는 저온에서,
NdFeB는 고온에서 감자가 쉬워지므로 두 온도 꼭짓점을 모두 봅니다.


6.   검증 계획
검증은 네 단계로 하고, 최종 기준은 2004년형 토요타 프리우스 구동모터입니다. 이 모터는 미국 오크리

 3. 프로젝트 한 문단과 검증 결과 한 줄(예: ‘프리우스 2004 측정 효율맵과 주요 영역에서 3%p 이내’
    — 실제 결과로 바꿉니다).
 4. 링크 2–3개: 요약 PDF, 데모, GitHub.
 5. 구체적인 요청: 학부연구생 가능 여부, 면담 시간.

면담 대비
    AI 도구로 코드를 작성한 사실은 숨기지 않습니다. ‘코드는 도구로 빠르게 만들고, 수식 유도와 검증
    은 직접 했다’는 설명이 설득력 있습니다.
    예상 질문: MTPA를 왜 쓰나, 약계자는 언제 시작되나, 철손은 왜 속도에 따라 늘어나나, 측정값과 차
    이가 나는 이유는 무엇인가, 페라이트 모터의 약점은 무엇인가.
    한계를 먼저 말합니다: 2D FEA, 정상상태 모델, 인버터 손실 단순화 등.
연구실 관심에 맞춘 변형도 준비합니다. 울산대에는 대리모델 최적화와 효율맵 계산 속도를, 한양대에는
주행사이클 전비와 페라이트 비교를 앞에 둡니다.
